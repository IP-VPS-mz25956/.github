<h2>购买流程可以压成五步</h2>
<p>定用途、选配置、确认地址属性、确认条款、收货验收。五步里前两步是常规 VPS 采购都会做的，后三步是这类产品特有的，也是最容易出问题的部分。</p>
<p>很多人把注意力全放在配置和价格上，忽略了后三步，结果买到手才发现地址属性不对或者条款不允许自己的用法。</p>

<h2>第一步：定用途，它决定配置方向</h2>
<p>如果只是做网络出口、跑轻量转发，配置要求很低，重点是带宽与地址属性。如果要在这台机器上跑应用、做数据处理，配置要求就上来了，CPU 与内存都要考虑。</p>
<p>还有一种用途是「作为环境的一部分」，比如配合浏览器环境做账号运营。这类用途对配置要求低，但对地址属性、稳定性、独享程度要求高。先定用途，才知道钱该花在哪。</p>

<h2>第二步：选配置，四项参数怎么定</h2>
<p>CPU：转发类用途一两核足够，跑应用按实际负载定。内存：随并发连接数增长，是最容易被低估的一项。硬盘：系统加日志，几十 G 够用，要留日志空间。</p>
<p>带宽：香港的国际带宽成本高，很多方案限量或限速。这一项要按实际流量估，别只看峰值速度。四项里最该多留余量的是内存，因为它不足时会直接导致服务不稳定。</p>

<h2>第三步：确认地址属性与独享</h2>
<p>要问清三件事：地址在公开数据库里标为什么类型、是否独享、以及是否可指定运营商。三件事都影响你买的东西是否符合预期。</p>
<p>要求对方提供归属查询结果作为参考，收货后自己再查一遍。两边的结果应当一致，不一致就以自己的查询为准并立即提出。</p>

<h2>第四步：确认条款允许的范围</h2>
<p>香港对网络服务有相应管理规定，服务商也会在条款里写明允许与禁止的用途。要确认自己的使用方式在允许范围内，包括能否自建某些服务、是否限制并发、是否有流量公平使用条款。</p>
<p>这一步最容易被跳过，因为条款长、读起来枯燥。但它决定了你付款后会不会被限速或停服，值得花十分钟。</p>

<h2>第五步：收货验收</h2>
<p>验收四项：地址类型与归属是否符合预期、出口是否独享、带宽与标称是否一致、连续几天是否稳定。四项都过再正式投入使用。</p>
<p>验收期内发现问题，处理成本最低。过了这个窗口，交涉难度会明显上升。</p>

<h2>系统与初始设置</h2>
<p>装完系统先做三件事：更新到当前稳定版、改默认远程端口并改用密钥登录、关闭不需要的服务。这台机器会长期对外，默认配置是最常见的入口。</p>
<p>然后设置时间同步。香港时区与内地一致，但如果业务涉及其他地区，日志时间要能对上，否则排障时会看错时间线。</p>

<h2>上线后的三件事</h2>
<p>一是限制访问来源，别让入口对全网开放。二是配置日志与监控，至少能看出流量与连接的变化。三是记录配置，写一份简单的说明文档，方便交接与排障。</p>
<p>三件事都不难，但缺了任何一件，出问题时的排查成本都会成倍上升。</p>

<h2>常见问答</h2>
<h3>香港住宅 VPS 和普通 VPS 差别在哪？</h3>
<p><strong>答：</strong>主要在地址属性。配置层面差别不大，价格差异主要来自地址的住宅特征与稀缺性。</p>
<h3>配置要多高？</h3>
<p><strong>答：</strong>看用途。纯转发低配即可，跑应用按实际负载定。别为用不上的算力付钱。</p>
<h3>怎么确认地址是住宅？</h3>
<p><strong>答：</strong>查公开数据库的用途标注，并交叉验证多家。标为住宅才算。</p>
<h3>能自己装软件吗？</h3>
<p><strong>答：</strong>多数可以，但要确认条款允许范围。部分产品限制某些服务的自建。</p>
